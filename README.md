# Parry

Parry is a landing page for an upcoming product (on-device AI assistant concept).

What’s live:
- Browser-ready showcase built from the provided `Resources/` design files (mobile and web art).
- Lightweight React/Babel demo render directly in the page (no build step required).
- Public GitHub Pages deployment powered by GitHub Actions.

Run locally:
1. Open `index.html` in your browser.

Deploy:
1. Push to `main`.
2. GitHub Actions uploads the repo as a static artifact and publishes via Pages.

If Pages is enabled in repository settings, the site will be available at:
- `https://EvergreenTree.github.io/parry`
